

# Healthcare Education Website — "The Deming's House"

A premium, single-page healthcare education website with cinematic animations, built with React + Vite + Tailwind CSS + Framer Motion.

---

## Design System
- **Colors**: Primary `#0B4F6C`, Accent `#00B4D8`, Background `#F9FAFB`, Text `#1F2933`, Muted `#6B7280`
- **Fonts**: Poppins (headings), Inter (body)
- **Feel**: Calm, trustworthy, premium healthcare aesthetic

---

## Sections (Single Scrolling Page)

### 1. Sticky Navbar
- Logo on the left, navigation links on the right (Home, About, Why Choose Us, Course, FAQ)
- Shadow appears on scroll, active section highlighting

### 2. Hero Slider
- Full-viewport hero with image slider (healthcare imagery with dark gradient overlays)
- Bold headline, subheading, and glowing CTA button
- Smooth auto-advancing slides with fade transitions

### 3. About Section
- Two-column layout: image on left, text with checklist on right
- Slide-in and fade-up entrance animations on scroll

### 4. Services Section
- 4-card grid with icons, titles, and descriptions
- Cards lift on hover with shadow animation

### 5. Why Choose Us
- 8-card grid showcasing differentiators
- Staggered entrance animations as cards come into view

### 6. Course Details
- Two-column layout with course description and bullet-point benefits
- Covers: time-efficient learning, insurance training, medical tourism, marketing skills

### 7. Founder Quote
- Full-width section with large inspirational quote
- Soft fade-in animation, emotional and human feel

### 8. FAQ Accordion
- Expandable questions with smooth height animation
- Only one item open at a time, rotating arrow indicator

### 9. Certifications
- Logo row of certification badges
- Greyscale by default, color on hover

### 10. Footer
- Contact info, social links, copyright
- Back-to-top button

---

## UX Enhancements
- Scroll progress bar at the top of the page
- Smooth scroll behavior for anchor navigation
- Every section fades in on scroll (opacity + translateY)
- Lazy-loaded images with skeleton placeholders
- Fully responsive: mobile, tablet, desktop
- Accessible with semantic HTML and ARIA attributes

---

## Technical Notes
- All animations via Framer Motion + CSS transitions (platform compatible)
- Text-based logo placeholder (uploadable later)
- No backend needed initially — contact info displayed statically
- SEO meta tags, single H1, proper heading hierarchy, alt text on all images
